Présentation du TSP

Le problème du Voyageur de Commerce, aussi appelé Travelling Salesman Problem (TSP), est un problème d'optimisation très connu en algorithmique.

Le principe est simple : un voyageur doit visiter plusieurs villes une seule fois chacune puis revenir à sa ville de départ.

L'objectif est de trouver le trajet le plus court possible.

Pourquoi ce problème est difficile ?

Lorsque le nombre de villes augmente, le nombre de chemins possibles devient énorme.

Par exemple, avec seulement 10 villes, il existe déjà plusieurs centaines de milliers de trajets possibles.

Tester toutes les solutions devient donc beaucoup trop long pour de grandes instances.

Applications du TSP

Le problème du voyageur de commerce est utilisé dans de nombreux domaines :

  • Optimisation des livraisons
  • Transport et logistique
  • Création d'itinéraires GPS
  • Organisation de tournées
  • Robotique
  • Recherche en intelligence artificielle

Notre projet

Dans ce projet, nous avons développé un programme en C++ permettant de résoudre des instances du TSP.

Nous avons utilisé :

  • Un algorithme glouton
  • Une amélioration OR-opt
  • La lecture de fichiers .tsp
  • Une matrice de distances

Le but du projet est de comprendre comment construire puis améliorer une solution approximative du TSP.
